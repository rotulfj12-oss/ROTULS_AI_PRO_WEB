# ROTUL'S AI PRO — Web

Versi website statis ROTUL'S AI PRO untuk GitHub Pages.

## Fitur
- Tanya AI dengan OpenRouter
- Model selector dari OpenRouter
- Analisis gambar dan kamera
- Upload file
- Voice input menggunakan browser
- Riwayat lokal
- Ekspor Word/PDF/Excel/PowerPoint dari hasil AI
- Responsive untuk Mac dan HP

## Menjalankan
Buka `index.html` di browser atau deploy folder ini ke GitHub Pages.

API key OpenRouter dimasukkan melalui menu Pengaturan dan disimpan di localStorage browser. Jangan memasukkan API key ke repository.
